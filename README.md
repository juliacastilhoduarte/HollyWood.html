## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação semântica.
* **CSS3**: Estilização, Flexbox para o layout e animações de transição.
* **Google Fonts**: Tipografia personalizada.

## 🎨 Funcionalidades e Diferenciais
* **Layout Flexbox**: Design organizado através de `display: flex`.
* **Cards Interativos**: Efeitos de `:hover` com `transform` e `box-shadow` para melhor experiência do usuário.
* **Imagens Responsivas**: Ajuste automático de imagens dentro dos containers.
* **Bordas Estilizadas**: Uso de `border-radius` assimétrico para um visual moderno.
